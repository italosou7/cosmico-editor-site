COSMICO EDITOR — SITE PARA GITHUB PAGES

Arquivos:
- index.html: página inicial
- termos.html: Termos de Serviço
- privacidade.html: Política de Privacidade
- style.css: identidade visual e layout

COMO PUBLICAR:
1. Abra o repositório no GitHub.
2. Clique em Add file > Upload files.
3. Envie os quatro arquivos HTML/CSS (não é necessário enviar este LEIA-ME).
4. Clique em Commit changes.
5. Aguarde a implantação do GitHub Pages.

IMPORTANTE:
Revise os textos legais para refletirem exatamente a versão real do aplicativo, inclusive os recursos que enviam dados a APIs externas, logs, serviços de IA e integrações. A política foi redigida com base na informação de que as credenciais de integração ficam armazenadas localmente. Não representa aconselhamento jurídico nem garante aprovação do TikTok.
